Create and manage unlimited independent responsive custom tables with manual builder and AI/OCR image extraction for WordPress & Elementor.

== Description ==

**DEFE Custom Tables** is a lightweight, production-ready WordPress plugin that enables you to create and manage unlimited independent custom tables.

### Key Features:
* **Unlimited Independent Tables:** Each table (`[defe_table id="101"]`, `[defe_table id="102"]`) has its own rows, columns, headers, colors, borders, and settings.
* **Manual Interactive Table Builder:** Live grid editor to add/remove/duplicate rows and columns, reorder, and edit multiline cells.
* **Image -> Editable Table OCR Import:** Upload screenshots or table photos to automatically extract structured rows and columns.
* **Custom Headers & Footer Styling:** Customize header colors (green, blue, purple, custom), fonts, and optional Total/Summary row.
* **Automatic or Manual Totals:** Support for manual totals or automated SUM, COUNT, and AVERAGE operations.
* **100% Mobile Responsive:** Smooth horizontal touch scrolling without shrinking fonts or breaking site-wide layouts.
* **Elementor Free Compatibility:** Works right out of the box with Elementor Shortcode widget.
* **Isolated Scoped CSS:** Zero interference with existing WordPress, theme, or WooCommerce tables.

== Installation ==

1. Upload the `defe-custom-tables` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to **DEFE Custom Tables** in your admin menu to start creating tables.
4. Insert shortcode `[defe_table id="123"]` into any page, post, or Elementor Shortcode widget.

== Frequently Asked Questions ==

= Does it work with Elementor Free? =
Yes! Simply use the standard Elementor Shortcode widget and paste `[defe_table id="123"]`.

= How does Image OCR work? =
You can upload any screenshot of a table. The plugin parses the structure into editable cells, presents a review screen, and imports it directly into the standard Table Builder.
